# Native SSO in eSignet (Go) for Mobile Apps

**MOSIP Decode 2026 · Problem statement 03 · eSignet | Enable Native SSO in eSignet Go for Mobile Apps**

**Team AlphaQ.** One login in a vendor's first native app; silent, cryptographically bound sign-in in every other app
of that vendor on the same device. Implemented as **OpenID Connect Native SSO for Mobile Apps 1.0** on
eSignet (Go) and the ThunderID engine, with two Android reference apps, an automated end-to-end
test, a Postman collection and full documentation.

```
 Vendor Wallet (super app)                    eSignet (Go) + ThunderID                  Vendor Health (child app)
 ───────────────────────────                  ────────────────────────                  ─────────────────────────
 PAR + PKCE + DPoP (Key A)  ───────────────▶  OTP login, consent
 token (authorization_code) ───────────────▶  device_sso ⇒ device_secret (JWE) + id_token{ds_hash, sid}
 store id_token + device_secret
                            ◀── IPC (signature permission): id_token, device_secret, DPoP proof by Key A ──
                                              token exchange ◀───────────────────────────  subject=id_token, actor=device_secret
                                              ds_hash · sid · cnf.jkt · sub · vendor · scope ⊆ grant · consent
                                              access_token{cnf.jkt=Key A, act.sub=Wallet} ──▶  userinfo (DPoP by Key A)
```

## Verify it in ten minutes (no phone needed)

Prerequisites: Docker, git, Python 3, openssl.

```bash
git clone <this repository> && cd <this repository>
./scripts/fetch-backends.sh                                   # clones the two backend branches into repos/ (git-ignored)
docker compose -f deploy/docker-compose.yml up -d --build     # PostgreSQL, mock identity, eSignet (built from repos/), login UI
python3 mobile-sample/scripts/register_clients.py             # registers mosip-super-app, mosip-child-app, other-vendor-app
python3 tests/native_sso_e2e.py                               # drives the whole protocol; prints N/N checks passed
```

The stack listens on http://localhost:8088 (eSignet), http://localhost:3000 (login UI with the modern
theme), 8082 (mock identity) and 5455 (PostgreSQL); override with `ESIGNET_PORT`, `UI_PORT`,
`MOCK_PORT`, `DB_PORT` (and `ESIGNET_HOST` for the issuer URL). Test identity: UIN `1774231323`,
OTP `111111`. The captcha is the Cloudflare Turnstile dummy site key (`1x00000000000000000000AA`),
which passes by itself; no validator URL is configured locally.

Then import `postman/mosip_esignet_native_sso.postman_collection.json` with the generated
`*_local.postman_environment.json` into the Postman desktop app and run the collection top to
bottom, or build and install the two apps (see `mobile-sample/README.md`; a phone needs
`adb reverse tcp:8088 tcp:8088` and `adb reverse tcp:3000 tcp:3000`).

Developer mode (eSignet from source on the host, hot restarts) is in `docs/esignet.env.example`.

## Task coverage

| PS03 task | Status | Where |
|---|---|---|
| 1 `device_sso` scope | done | eSignet `deployment.yaml`, ThunderID protocol-scope handling |
| 2 token endpoint validates the scope for the client | done | ThunderID `authorization_code.go`, eSignet `device_secret_provider.go` |
| 3 `DeviceSecretProvider` interface | done | ThunderID `providers/interface.go` |
| 4 Generate / Validate device secret (signed-then-encrypted JWT with cnf.jkt, auth_id, exp, client_id, scope, acr, claims, iss) | done | eSignet `device_secret_provider.go` |
| 5 token endpoint invokes generation | done | ThunderID `authorization_code.go` |
| 6 response: access_token, id_token, device_secret | done | ThunderID token response |
| 7 child app fetches id_token + device_secret + DPoP proof via app-to-app IPC | done | `mobile-sample` `NativeSsoContract`, `NativeSsoProvider` |
| 8 child app token exchange, DPoP signed with the super app's key | done | `mobile-sample` `EsignetClient.exchangeDeviceSecret` |
| 9 token exchange grant: device-secret actor, ds_hash, sid, client enablement, cnf.jkt | done | ThunderID `token_exchange.go` |
| 10a child scope ⊆ super app scope | done | ThunderID `getScopes` |
| 10b `device_sso` rejected on exchange (explicit or inherited) | done | ThunderID `ValidateGrant`, `getScopes` |
| Bonus: re-consent in the child app | done | ThunderID `interaction_required`, eSignet derived consent, child app fallback |

`docs/design-document.md` §10 holds the spec-conformance matrix (OpenID Native SSO 1.0, RFC 8693,
RFC 9449) and §11 the threat model with the demo-only shortcuts.

## Unit tests

```bash
cd repos/thunderid/backend && go test ./internal/oauth/... ./pkg/thunderidengine/...
cd repos/esignet-go/esignet-service && go test ./...
cd mobile-sample && ./gradlew :nativesso-sdk:testDebugUnitTest   # JDK 17; SDK: codec, client assertions, ID-token verification, models
```

The GitHub Actions workflow `.github/workflows/sdk-tests.yml` runs the SDK tests and assembles both
apps on every push. `tools/demo_driver.js` drives the whole phone demo (Wallet login, Health silent
sign-in, re-consent) over adb and Chrome DevTools for screen recordings; `docs/submission-artefacts.md`
maps every organiser requirement to its evidence.
