# Pitch deck generator

`docs/pitch-deck.pptx` is generated by `build.js` (pptxgenjs, 16:9, Cambria / Calibri theme).

```bash
cd tools/deck
npm install pptxgenjs jszip            # once
SKILL=<path to the pptx skill dir> NODE_PATH=$PWD/node_modules node build.js ../../docs/pitch-deck.pptx
```

`SKILL` points at a directory containing `scripts/apply_theme.js` (writes the theme colours into the
deck after pptxgenjs has written it). Render for a visual check with LibreOffice:

```bash
soffice --headless --convert-to pdf --outdir /tmp docs/pitch-deck.pptx
gs -q -dNOPAUSE -dBATCH -sDEVICE=png16m -r60 -sOutputFile=/tmp/s-%02d.png /tmp/pitch-deck.pdf
```

Screenshots come from `docs/images/`.
